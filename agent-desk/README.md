# Agent Desk

Настоящее приложение для **Windows** (установщик `.exe`) и **Android** (`.apk`) в стиле Windows 98. Оно следит за ИИ-агентами и напоминает, когда нужно ответить или переслать сообщение. Python больше не нужен.

- **ПК**: значок в трее, всплывающие окна со звуком, запуск вместе с Windows. ПК хранит все данные и читает маркеры агентов.
- **Телефон**: те же агенты и напоминания по Wi-Fi во весь экран и уведомления в стиле Windows 98 со звуком приложения, даже с выключенным экраном. Кнопки «Копировать», «Переслал» и «Закрыть» работают и с телефона.
- **Другие компьютеры**: ПК и ноутбук одной Wi-Fi сети отправляют друг другу задачи.

Изменения по версиям — в [CHANGELOG.md](../CHANGELOG.md).

## Установка

### Windows

1. Скачайте `AgentDesk-Setup-<версия>.exe` из [Releases](https://github.com/purrfect0/AgentDesk/releases/latest) и запустите его. Права администратора не нужны: приложение ставится для текущего пользователя и создаёт ярлыки.
2. Установщик не подписан сертификатом, поэтому SmartScreen покажет предупреждение: **«Подробнее» → «Выполнить в любом случае»**.
3. Когда брандмауэр спросит, разрешите доступ в **частных сетях**. Без этого не подключатся ни телефон, ни другие компьютеры.
4. Приложение живёт в трее. Крестик окна его сворачивает, а полностью выйти можно через «Файл → Выход» или меню значка в трее. Автозапуск включается в «Вид → Запускать вместе с Windows».

Удалить приложение можно как обычно: «Параметры → Приложения». Данные остаются в `%USERPROFILE%\AgentDesk`.

### Android

1. Скачайте `AgentDesk-<версия>.apk` из [Releases](https://github.com/purrfect0/AgentDesk/releases/latest) прямо на телефон и откройте его. Если Android попросит, разрешите **«установку из неизвестных источников»** для браузера или файлового менеджера. Нужен Android 6 или новее.
2. Разрешите уведомления. Если телефон спросит про доступ к устройствам в локальной сети, разрешите и его.

### Подключение телефона к ПК

1. На ПК откройте **«Файл → Подключить телефон…»** (кнопка «Телефон»). Если доступ из Wi-Fi выключен, нажмите «Включить доступ из Wi-Fi». На экране появится QR-код.
2. В приложении на телефоне нажмите **«Сканировать QR-код»** и наведите камеру на экран ПК.
3. Если сканер недоступен, нажмите на ПК «Копировать», перешлите ссылку себе (Telegram, почта или общий буфер), вставьте её в приложении и нажмите «Подключить». Ссылка выглядит как `http://192.168.x.x:8098/?key=…`.

Телефон запомнит ПК, а сменить его можно в «Файл → Подключение к ПК». Если ссылка утекла, нажмите на ПК «Сменить ключ». Старые ссылки перестанут работать, и телефон попросит новую. С телефона нельзя менять папки, доступ из Wi-Fi и ключ: это делается только на ПК.

### Уведомления с выключенным экраном

Пока телефон подключён к ПК, фоновая служба ждёт события от ПК и показывает уведомление в стиле Windows 98 со звуком приложения, даже когда экран выключен. Служба запускается и после перезагрузки телефона, а в шторке при этом висит тихий значок «На связи с ПК».

Всё про уведомления собрано в «Вид → Уведомления на телефоне…»: там можно выключить фоновую связь, проверить уведомление («Проверить», затем выключить экран на 10 секунд) и открыть системные настройки уведомлений, батареи и приложения.

Nubia и RedMagic, как и Xiaomi, Huawei, Honor, OPPO, vivo и Samsung, усыпляют фоновые приложения сильнее обычного Android. Если уведомления опаздывают:

1. «О приложении…»: включите **автозапуск** и работу в фоне.
2. «Батарея…»: выберите **«Без ограничений»**.
3. В списке недавних приложений закрепите Agent Desk замком, чтобы очистка памяти его не закрывала.

### Связь ПК и ноутбука

Agent Desk на компьютерах одной Wi-Fi сети находят друг друга и передают задачи. Например, агент на ноутбуке закончил работу, а переслать её надо агенту на ПК.

1. На обоих компьютерах включите доступ из Wi-Fi: «Файл → Подключить телефон…» → «Включить доступ из Wi-Fi». Брандмауэру Windows разрешите Agent Desk в **частных сетях**: нужны TCP 8098 (задачи) и UDP 8099 (поиск в сети).
2. На одном компьютере откройте **«Файл → Другие компьютеры…»** (то же есть в меню значка в трее). Второй появится в списке «Найдены в Wi-Fi», нажмите «Подключить». Если его там нет, введите адрес вручную: `192.168.1.20`, `laptop:8098` или ссылку `http://…`.
3. На втором компьютере всплывёт окно с запросом. Сверьте четырёхзначный код с первым компьютером и нажмите «Разрешить».
4. Выберите задачу в «Нужно сделать» и нажмите **«Отправить»** на панели. На другом компьютере задача появится с пометкой «с «Рабочий ПК»» и всплывающим окном, а здесь закроется с пометкой «отправлено → «Ноутбук»».

Галочка в «Другие компьютеры» включает автоотправку: если адресата пересылки нет на этом компьютере, но он работает на подключённом, напоминание уходит туда само. Там же меняется имя этого компьютера.

Связь запоминается на обоих компьютерах, у каждой пары свой ключ. Убрать компьютер можно кнопкой «Отключить». Телефон видит подключённые компьютеры и может отправлять на них задачи, а новые связи заводятся только на ПК.

## Переход со старого Agent Board (Python)

1. Закройте старый Agent Board и уберите его из автозагрузки (ярлык в `shell:startup`). Оба приложения используют порт 8098, и при конфликте Agent Desk скажет «Порт 8098 занят».
2. Установите Agent Desk. При первом запуске он сам заберёт из `%USERPROFILE%\AgentBoard` папки агентов, настройки и открытые напоминания. Старая папка не изменяется.
3. Обновите текст для агентов: кнопка «Агентам» («Справка → Инструкция для агентов…») → скопировать. Номера теперь вида `AD-12`, но старые `AB-12` в подтверждениях тоже принимаются.
4. Телефон нужно подключить заново через новое приложение.

## Где взять файлы (сборка через GitHub)

Установщики собирает GitHub Actions (`.github/workflows/agent-desk.yml`), ничего ставить на ПК не нужно.

1. Каждый push в `main` прогоняет тесты ядра и собирает оба файла: **Actions → Agent Desk → последний запуск**, внизу архивы `AgentDesk-Windows` (.exe) и `AgentDesk-Android` (.apk). Запустить сборку вручную можно кнопкой «Run workflow».
2. Для релиза поднимите версию в `package.json` и `mobile/package.json` и создайте тег, например `agent-desk-v2.2.0`. Файлы появятся в **Releases**, и телефон сможет скачать APK оттуда напрямую.

### Постоянная подпись APK (чтобы обновляться без удаления)

Android ставит обновление поверх старой версии, только если подпись совпадает. Один раз создайте ключ (нужна Java):

```
keytool -genkeypair -v -keystore debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
```

Затем добавьте его в GitHub: **Settings → Secrets and variables → Actions → New secret**, имя `ANDROID_DEBUG_KEYSTORE`, значение берётся из base64 файла. В PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("debug.keystore")) | Set-Clipboard`. Без секрета каждая сборка подписывается новым ключом, и перед обновлением старое приложение придётся удалить.

### Сборка у себя (необязательно)

Нужен Node.js 20+, а для Android ещё JDK 21 и Android SDK.

```
cd agent-desk
node scripts/fetch-assets.js       # 98.css и значки Win98 (один раз)
npm install
npm test                           # тесты ядра
npm start                          # запуск без установки
npm run dist:win                   # dist/AgentDesk-Setup-<версия>.exe

cd mobile
npm install && npm run web
npx cap add android && npx capacitor-assets generate --android
node scripts/patch-android.js && npx cap sync android
cd android && ./gradlew assembleDebug
```

Картинки для страницы на GitHub рисует `node scripts/make-readme-art.js`, шрифт с кириллицей `node scripts/make-font.js`.

## Как устроено

```
agent-desk/
  core/desk.js        ядро: маркеры, напоминания, подтверждения, HTTP для телефона (Node.js, без зависимостей)
  core/peers.js       связь с другими Agent Desk: поиск в Wi-Fi (UDP 8099), пары по коду, отправка задач
  core/test/          тесты ядра: node --test core/test/desk.test.js
  desktop/            приложение для Windows (Electron): окно, трей, всплывающие окна, автозапуск
  web/                общий интерфейс Win98 для ПК и телефона; web/fonts: пиксельный шрифт с кириллицей
  mobile/             приложение для Android (Capacitor); mobile/native: фоновая служба и уведомления Win98
  scripts/            98.css и значки, шрифт, картинки README, подготовка Android, иконка
```

Агенты по-прежнему пишут JSON-маркеры в папки из «Файл → Папки с маркерами…». Файл сначала записывается как `.tmp`, потом переименовывается:

```json
{"agent": "Codex", "state": "waiting", "waiting_for": "owner_forward", "to": "Astra",
 "task": "review PR", "message": "Проверь PR #12", "ack": ["AD-7"]}
```

`state` принимает значения `working | waiting | done | blocked | idle`, а `waiting_for` значения `owner_input | owner_forward | reviewer | coordinator_review | resource | model_limit | assignment`. Полный текст для агентов лежит под кнопкой «Агентам». Испорченные файлы переносятся в `bad/<дата>/` и показываются в предупреждениях.

## Ограничения

- **Телефон и другие компьютеры работают только в той же Wi-Fi сети**, и только пока Agent Desk на ПК запущен. Связь идёт по http внутри домашней сети и защищена ключами, но не шифруется. В общественных сетях доступ из Wi-Fi лучше выключать.
- **Уведомления на телефоне** приходят от фоновой службы, без push-серверов в интернете: всё остаётся дома. Если оболочка телефона всё-таки её усыпит, помогут настройки из раздела «Уведомления с выключенным экраном». Важное всегда видно и на ПК во всплывающих окнах.
- Установщик для Windows не подписан сертификатом (отсюда предупреждение SmartScreen), APK подписан отладочным ключом, Google Play не нужен. iPhone не поддерживается: для него нужен Mac и платный аккаунт Apple.
- Пока собирается только Windows x64. Electron может собрать и macOS/Linux, но там не проверялось.
