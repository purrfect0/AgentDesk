# Что нового

## 2.2.0 — 10 ноября 2026

**ПК и ноутбук**
- Связь компьютеров одной Wi-Fi сети: «Файл → Другие компьютеры…», поиск в сети, связь по четырёхзначному коду и кнопка «Отправить» на панели. На другом компьютере задача появляется с пометкой, откуда пришла, а здесь закрывается с пометкой, куда ушла. Пересылку агенту, который работает на другом компьютере, можно отправлять туда автоматически.
- Значки больше не моргают при обновлении: окно меняет только изменившиеся строки.
- Всплывающие окна говорят, что сделать: кому переслать результат или на чей вопрос ответить.
- В «Справка → О программе» видна версия.

**Телефон**
- Уведомления приходят и с выключенным экраном: фоновая служба держит связь с ПК и запускается после перезагрузки телефона. Настройки и проверка в «Вид → Уведомления на телефоне…».
- Уведомления в стиле Windows 98 со звуком приложения вместо системного.
- Приложение занимает весь экран, без строки состояния.
- Русский текст набран пиксельным шрифтом Windows 98, как и английский.

**Сборка и страница на GitHub**
- Тест проверяет, что установщик содержит все файлы ядра и что версии для ПК и телефона совпадают. CI проверяет синтаксис скриптов окна, телефона и сборки.
- На странице появились скриншоты, значки сборки и версии, разделы про уведомления и связь компьютеров. Кириллица на картинках набрана пиксельным шрифтом. Добавлен файл LICENSE.

## 2.1.0 — 10 ноября 2026

- Подключение телефона по QR-коду.
- Всплывающие окна складываются в стопку, как в центре уведомлений Windows 11, и уезжают сами через 20 секунд.
- Акцентные анимации для того, что требует внимания.
- Квадратные углы окон, исправлены галочки в меню, классическая иконка.
- Страница на GitHub в стиле Windows 98.

## 2.0.0 — 10 ноября 2026

- Agent Desk вместо Agent Board на Python: приложение для Windows (Electron) и Android (Capacitor) с общим интерфейсом в стиле Windows 98.
- Сборка `.exe` и `.apk` в GitHub Actions, релизы по тегу `agent-desk-v*`.
