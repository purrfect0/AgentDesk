# Исправления интерфейса 2.3.1

В 2.3.0 номер карточки уже существовал, но окно подробностей показывало task_id/message_id в главных полях. В 2.3.1 карточка и её подробности показывают AD/AT-номер; служебные UUID доступны только в раскрываемом разделе «Технические данные». UUID остаются в API, синхронизации и копируемом тексте для агента: не заменяйте их локальным номером в ACK.

Доставленное сообщение не означает, что агент должен быть повторно запущен. Оно показывается как «доставлено · ожидает получения», без мигания и увеличения счётчика действий владельца. Закрытые сообщения не превращаются в требование запуска. Приёмка задачи по-прежнему независима от доставки/получения.

В основном списке задач вместо шестнадцатеричного device_id показывается имя компьютера. Вместо технического session_id показан понятный статус привязки/активности. Исходные значения сохранены в диагностике и в заданиях для агентов; сопоставление сессий не меняется.

Файловая синхронизация не является обязательной почтой AgentDesk. Основные вкладки: Агенты, Журнал, Задачи. Дополнительные файлы доступны через «Файл → Файлы проектов (дополнительно)», выключены по умолчанию и включаются только локальным владельцем. Выключение не удаляет папки, файлы или сохранённый индекс. Синхронизация карточек, сообщений, задач и ACK продолжает работать.

Для применения замените приложение на обоих ПК установщиком 2.3.1. Во время подготовки сборки рабочие данные и установленные приложения не менялись. Старая опубликованная 2.3.0 не перезаписывалась.
